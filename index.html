3下载到本地目录

下载完成后会自动在目录中生成本地仓库索引（repodata / Packages.gz），整个目录拷贝到离线 Linux 即可作为本地源使用。

下载 / 加载任务

使用说明

① 选择目标 Linux 的发行版体系、版本、镜像源与架构，点击「加载元数据」（大仓库需等待数十秒）。
② 搜索并勾选需要的包，点击「解析依赖」，确认依赖清单与未满足缺口。
③ 填写保存目录后点击「开始下载」，实时日志在上方任务区显示。
④ 下载完成后，将整个目录拷贝到离线 Linux：
# RHEL 系 (yum/dnf):
yum install ./目录/*.rpm
# 或配置本地源 baseurl=file:///目录

# Debian 系 (apt):
apt install ./目录/*.deb
# 或 sources.list 添加: deb [trusted=yes] file:///目录 ./

选择保存目录（服务器本机目录）
